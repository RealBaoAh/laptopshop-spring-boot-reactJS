Giới Thiệu Đồ Án
Website Thương Mại Điện Tử Bán Máy Tính Xách Tay (Spring Boot + ReactJS)
  • Khách hàng duyệt sản phẩm, lọc/tìm kiếm thông minh, quản lý giỏ hàng, đặt mua và xem lịch sử đơn hàng.
  • Admin quản trị hệ thống toàn diện: thống kê đơn hàng, quản lý danh mục sản phẩm, người dùng và trạng thái giao hàng.
Thành viên: Nguyễn Bảo Nguyên (22130189) & Nguyễn Bảo Anh (22130200)
Giảng viên hướng dẫn: ThS. Lê Phi Hùng
Phân Công
Công Việc
Nguyễn Bảo Nguyên — 22130189
Frontend & Integration: Thiết kế giao diện React SPA responsive (Trang chủ, Sản phẩm, Chi tiết sản phẩm, Giỏ hàng, Đặt hàng). Quản lý state toàn cục với React Context (`AuthContext` & `CartContext`), tích hợp APIs bất đồng bộ (Axios), phát triển tính năng active navigation link, bộ lọc thông minh, và thanh tìm kiếm tự động gợi ý sản phẩm tức thì.
Nguyễn Bảo Anh — 22130200
Backend & Database: Xây dựng cấu trúc dự án Spring Boot MVC. Thiết kế Database Schema MySQL (các mối quan hệ thực thể JPA Hibernate `@OneToMany`, `@ManyToOne`). Tích hợp cơ chế bảo mật phân quyền với `Spring Security 6` (BCrypt, Session JDBC). Thiết lập Validation đầu vào nâng cao (`@RegisterChecked`, `@StrongPassword`) và triển khai API endpoints.
Kiến Trúc
Hệ Thống
Mô Hình Tổng Quan
Ứng dụng được thiết kế theo kiến trúc Client-Server tách biệt hoàn toàn nhằm nâng cao tính mở rộng và hiệu năng:
  • Frontend (React SPA): Xây dựng bằng React 19, TypeScript, và Vite giúp tăng tốc phát triển. Gọi các API bất đồng bộ (Axios) và trao đổi dữ liệu định dạng JSON.
  • Backend (Spring Boot): Đóng vai trò là RESTful API Service. Tiếp nhận request, xử lý nghiệp vụ thông qua tầng Service và ánh xạ dữ liệu bằng Spring Data JPA.
  • Database & Session: Hệ quản trị cơ sở dữ liệu MySQL. Trạng thái phiên làm việc (Session) được lưu trữ tập trung trong database bằng Spring Session JDBC thay vì RAM Tomcat.
Kỹ Thuật
Cơ Bản
Hệ thống áp dụng các nguyên lý cốt lõi của công nghệ web hiện đại, đảm bảo tính bất đồng bộ cao và kiến trúc phân lớp chuẩn hóa.
Frontend — React SPA
Kiến trúc dựa trên Component giúp giao diện tái sử dụng tối đa. Routing điều hướng động qua `react-router-dom` phân chia rõ giao diện người dùng và Admin Layout. Giao diện responsive trên mobile/tablet nhờ Tailwind CSS.
Bất Đồng Bộ — Async / Ajax
Trao đổi dữ liệu không tải lại trang với thư viện Axios qua async/await. Tìm kiếm tự động gợi ý sản phẩm (Auto-suggest), thêm vào giỏ hàng, cập nhật số lượng và tổng tiền tức thì qua trạng thái dùng chung (React Context).
MVC Architecture — Backend
Phân tách rõ ràng: Model (JPA Entity tương tác DB), View (Trả dữ liệu JSON thông qua ResponseEntity của Controller), Controller (Định nghĩa endpoints nhận REST requests), và Service layer (Nghiệp vụ nghiệp vụ logic tách biệt).
Bảo Mật (Security)
Cấu hình Spring Security 6 quản lý filter chain chặt chẽ. Mã hóa mật khẩu người dùng bằng thuật toán một chiều BCrypt. Phân quyền truy cập dựa trên vai trò (Role-Based Access Control) cho đường dẫn `/admin/**` và CORS config ngăn chặn truy cập trái phép.
Validation 2 Lớp
Frontend bắt lỗi tức thì. Backend tích hợp Hibernate Validator kiểm tra dữ liệu bằng các annotation chuẩn (`@Email`, `@Size`). Triển khai custom annotation `@RegisterChecked` để validate tính trùng khớp mật khẩu và kiểm tra trùng email đăng ký.
Spring Data JPA
Ánh xạ quan hệ thực thể (ORM) giữa các bảng quan trọng: `User` - `Order` - `OrderDetail` và `Cart` - `CartDetail` - `Product`. Kế thừa `JpaRepository` hỗ trợ tự động hóa CRUD, phân trang và sắp xếp sản phẩm hiệu quả.
Lưu Phiên Tập Trung
Áp dụng thư viện `Spring Session JDBC` lưu trữ trạng thái người dùng trực tiếp vào cơ sở dữ liệu (`SPRING_SESSION`). Đảm bảo hệ thống hoạt động ổn định và sẵn sàng cho việc phân tải (Load Balancing) mà không mất thông tin giỏ hàng/phiên làm việc.
Kỹ Thuật
Nâng Cao
Hệ thống tích hợp các cơ chế bảo mật cấp độ doanh nghiệp, cấu hình JPA tối ưu hóa câu lệnh SQL và quản lý dữ liệu chặt chẽ qua cơ chế kiểm tra dữ liệu hợp lệ đầu vào.
